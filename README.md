# Java Application

## 📌 Overview
This is a Java application built using Spring Boot, Maven, Gradle.  
It performs initializing records for service offers and technology stacks for ecommerce it solutions.

---

## 🚀 Features
- Fetch service offers and technology stacks

---

## 🛠️ Technologies Used
- Java 17+
- Spring Boot
- Maven/Gradle
- PostgreSQL

---

## Pre-requisites
In PostgreSQL or pgadmin, create a database "ecommerce"

## To run the application in windows
Run the Command:
"gradlew bootRun"
